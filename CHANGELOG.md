# История изменений

## 0.1.5 — 2026-10-16

- Плитки: `state_map` — подмена показанного значения (например, `0` → «всё в порядке»);
  `level_attribute` — цвет плитки из атрибута сущности.

## 0.1.4 — 2026-10-15

- Плитка с `tap_action: {action: list, attribute: …}` раскрывает список из атрибута прямо в карточке
  (например, пакеты, которые можно обновить).

## 0.1.3 — 2026-10-15

Первая публичная версия.

- Секции `tiles`, `meters`, `addons`, `updates`, `table`, `buttons` в одной карточке.
- Плитки: статичные (`value`, `sub`) — например, IP-адрес со ссылкой на веб-интерфейс; `binary` по атрибуту
  (`attribute` + `ok_state`, `fail_level: warn`), вторая строка из атрибута (`secondary_attribute`).
- Плитки: версии из `update.*` с пометкой «доступна X», время «назад / через / с», длительность, `binary_sensor` (есть / нет),
  числа с порогами `warn` / `bad` (`below: true` — плохо, когда меньше), вторая строка из другой сущности
  (время показывается как «35 мин назад»).
- Шкалы: процент, `max` числом или сущностью, `free: true` для «свободно из всего».
- Аддоны из Supervisor API: состояние, версия, CPU и RAM, перезапуск или запуск с подтверждением, обновление через
  стандартный диалог HA; без прав администратора — по сущностям.
- Обновления: все `update.*` с доступной версией, тип (Система, HACS, Zigbee…), клик открывает стандартный диалог установки.
- Таблица сущностей; на узкой карточке переворачивается (параметры становятся строками).
- Кнопки действий с подтверждением (`confirm`), опасные выделяются (`danger`).
- Тёмная и светлая темы через CSS-переменные HA, адаптивная вёрстка.
